# Fork patches

This is an unofficial fork of [touchHLE/touchHLE](https://github.com/touchHLE/touchHLE).

The `trunk` branch stays a plain mirror of upstream plus fork-only assets (this
directory and `.github/workflows/build-android.yml`). The actual source changes
live here as patch files, so re-syncing with upstream is a matter of merging
`trunk` and re-applying them. The `release` branch is generated by
`trunk` + these patches, and is what the APK is built from.

| Patch | What it does |
| --- | --- |
| `0001-no-preview-branding.patch` | Removes the `PREVIEW` watermark/branding and switches to the standard launcher icon; pins the `org.touchhle.android.ayaka` application ID and matching provider authority; adds release signing. |
| `0002-remove-upstream-release-workflow.patch` | Deletes upstream's release workflow, which would otherwise build macOS/Windows/Android on every push to this fork and burn Actions minutes. |

Apply manually with:

```sh
git apply --3way patches/*.patch
```

If upstream rewrites one of the touched hunks, the apply will fail loudly
instead of silently producing a wrongly branded build; regenerate the patch
against the new upstream source at that point.
